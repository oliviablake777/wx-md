## 任务拆分 tasks.md
作为**管理者**，我们不能直接抛给AI一个宏大的任务，然后希望它完美的交付。
要想对待新员工一样，将复杂项目拆分为清晰、具体、可执行的小任务。

## 为什么不能给AI 分配大任务
1. 上下文限制（记忆）
处理过程里面可能会遗忘早期的关键细节（Agent.md）
2. 细节处理能力下降
一次性处理的内容越多，AI对每个细节的关注度就越低。

## 如何进行有效的任务拆分
1. 启动任务划分
2. 审查与迭代

## 项目规则 

AI编程助手，如何保证它像**团队成员一样**，一样严格遵守项目的规划和任务，而不是自由发挥。

1. 任务执行边界 AI何时开始，何时停止
2. 代码风格，确保生成代码的统一性和可读性。
3. 技术栈遵循 要求AI 使用制定的语言和框架
4. 沟通方式 规定AI如何响应和提问。
