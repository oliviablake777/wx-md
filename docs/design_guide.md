# md-wx 组件设计指南

本文档基于当前的 UI/UX 设计原型，为 md-wx 组件的开发提供详细的设计规范和实现指导。

## 1. 设计理念

### 1.1 核心设计原则

- **玻璃拟态设计**：采用现代化的玻璃拟态（Glassmorphism）设计语言
- **渐进式增强**：从基础功能到高级特性的渐进式体验设计
- **微信原生适配**：深度适配微信公众号的原生设计语言和用户习惯
- **无障碍访问**：确保所有用户都能轻松使用组件功能

### 1.2 视觉风格

- **背景系统**：采用渐变背景 + 毛玻璃效果
- **层次结构**：通过阴影、透明度、模糊效果营造空间层次感
- **动画过渡**：使用 cubic-bezier(0.4, 0, 0.2, 1) 缓动函数
- **色彩系统**：基于主题的智能色彩算法，确保各主题下的最佳可读性

## 3. 组件设计规范

### 3.1 设置面板 (SettingsPanel)

#### 3.1.1 布局特性

- **定位方式**：sticky 粘性定位
- **背景效果**：rgba(255, 255, 255, 0.15) + backdrop-filter: blur(25px)
- **边框样式**：1px solid rgba(255, 255, 255, 0.25)
- **阴影效果**：0 8px 32px rgba(0, 0, 0, 0.12)

#### 3.1.2 按钮规范

- **尺寸**：桌面端 padding: 8px 10px，移动端 padding: 6px 8px
- **字体大小**：桌面端 16px，移动端 14px
- **圆角**：12px
- **悬停效果**：translateY(-2px) + scale(1.02)
- **动画时长**：0.3s cubic-bezier(0.4, 0, 0.2, 1)

#### 3.1.3 主题选择器

- **下拉菜单**：最小宽度 220px
- **选项间距**：padding: 12px 16px
- **悬停动画**：translateX(6px) + scale(1.02)
- **激活状态**：右侧显示 ✓ 图标

## 5. 响应式设计

### 5.1 断点系统

- **桌面端**：> 768px
- **平板端**：481px - 768px
- **移动端**：≤ 480px

### 5.2 适配策略

#### 5.2.1 桌面端 (> 768px)

- 完整功能展示
- 最佳视觉效果
- 丰富的交互动画

#### 5.2.2 平板端 (481px - 768px)

- 调整内边距和字体大小
- 保持核心功能
- 优化触摸交互

#### 5.2.3 移动端 (≤ 480px)

- 紧凑布局设计
- 简化动画效果
- 优化单手操作

## 6. 交互设计

### 6.1 动画规范

#### 6.1.1 缓动函数

- **标准过渡**：cubic-bezier(0.4, 0, 0.2, 1)
- **弹性效果**：cubic-bezier(0.68, -0.55, 0.265, 1.55)
- **快速响应**：cubic-bezier(0.25, 0.46, 0.45, 0.94)

#### 6.1.2 动画时长

- **微交互**：0.15s - 0.2s
- **标准过渡**：0.3s - 0.4s
- **复杂动画**：0.5s - 0.8s

### 6.2 反馈机制

#### 6.2.1 悬停效果

- **按钮**：轻微上移 + 缩放 + 阴影增强
- **卡片**：上移 + 阴影扩散
- **链接**：颜色渐变 + 下划线动画

#### 6.2.2 点击反馈

- **按钮**：短暂缩放效果
- **复制成功**：Toast 提示 + 图标动画
- **主题切换**：平滑颜色过渡

### 6.3 加载状态

- **骨架屏**：内容加载时的占位效果
- **渐入动画**：fadeIn 0.5s ease
- **进度指示**：适当的加载反馈
## 7. 可访问性设计

### 7.1 键盘导航

- 所有交互元素支持 Tab 键导航
- 明确的焦点指示器
- 合理的 Tab 顺序

### 7.2 屏幕阅读器

- 语义化的 HTML 结构
- 适当的 ARIA 标签
- 有意义的替代文本

### 7.3 色彩对比

- 确保文本与背景的对比度 ≥ 4.5:1
- 重要信息不仅依赖颜色传达
- 支持高对比度模式

## 8. 性能优化

### 8.1 渲染优化

- 使用 CSS transform 而非改变布局属性
- 合理使用 will-change 属性
- 避免不必要的重绘和回流

### 8.2 资源优化

- 图标使用 SVG 格式
- 字体文件按需加载
- CSS 代码压缩和优化

### 8.3 交互优化

- 防抖处理频繁操作
- 虚拟滚动处理长列表
- 懒加载非关键资源

- 使用 React Context 管理全局主题状态
- 使用 useState 管理组件内部状态

### 9.3 样式实现

- 使用 CSS Modules 确保样式隔离
- 使用 CSS 自定义属性实现主题切换
- 使用 PostCSS 进行样式预处理
